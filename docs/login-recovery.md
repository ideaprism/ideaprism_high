# 배포 로그인 직후 DB 연결 오류 수정 — 2026-11-03

보성고 코드 로그인 직후 오류 화면이 나오고 reload로 접속된다는 제보를 배포 서버 기록으로 확인했다. 2026-11-03 08:12 KST의 GET /에서 `Connection terminated due to connection timeout`이 발생했다. 학교 세션을 조회하던 첫 화면에서 15초 연결 시간이 초과되었으며, 로그인 코드가 틀렸다는 오류와는 다르다.

## 수정

- Vercel 공식 `attachDatabasePool`로 요청 종료 후 유휴 연결이 정리되도록 등록했다. Pool의 유휴 연결 error 이벤트도 처리해 요청 작업자가 예외로 종료되지 않도록 했다.
- PostgreSQL 연결 단절·연결 시간 초과에 한해 트랜잭션 밖 읽기 요청을 동일한 SQL·동일한 권한 매개변수로 한 번만 재시도한다.
- 발급·사용 횟수 갱신 등 쓰기와 트랜잭션 전체는 재실행하지 않는다. 권한 오류·SQL 오류도 재시도하지 않는다. 재시도마저 실패하면 인증을 우회하지 않고 오류로 종료한다.
- 같은 서버 렌더 요청에서 layout과 page가 중복 호출하는 학교 세션 조회를 React cache로 합쳤다. 요청 간 세션이나 사용자 권한을 전역 캐시하지 않는다.

## 검증

실제 배포에서 발생한 연결 시간 초과를 주입한 테스트가 수정 전 실패하고 수정 후 통과했다. Vercel Pool 수명주기 등록, 읽기 재연결의 권한 매개변수 보존, 재시도 횟수 제한, 쓰기 미재실행, 트랜잭션 롤백, SQL/권한 오류 미재시도, 유휴 연결 오류 처리를 검사했다. 전체 서버 테스트 99개와 타입 검사·변경 파일 ESLint가 통과했다. 운영 의존성 npm audit 0.
