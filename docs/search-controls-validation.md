# 검색 화면 수정 검증 — 2026-11-02

- 실제 조회 횟수 집계가 없는 고정 인기검색어는 사용자 요청의 대안에 따라 홈·검색 화면에서 제거했다.
- 검색 버튼 옆과 결과 건수 옆에 모든 데이터 보기 버튼을 추가했다. 검색어, 학년, 문제 유형, SCAMPER, 연도 범위, 페이지, URL 필터를 초기화한다. 로그인한 학교의 권한은 유지한다.
- 검색 응답의 학년은 원본 grade_year를 사용한 1·2·3학년이다. 원본 JSON의 학교급 grade_id는 변경하지 않고 응답에서 학년 필터 값으로 변환한다.
- 검색/상세 응답에 원본 award_year를 전달한다. 연도는 추정하지 않았으며 원본에 2015~2026년이 이미 있다. 학교 전체 자료에서 연도 범위를 구하므로 검색 결과가 0건이어도 조절할 수 있다.
- SCAMPER 아래 두 손잡이 연도 바를 추가했다. 양 끝을 포함하고 교차하지 않으며, 동일 연도로 좁힌 후에도 다시 늘릴 수 있다. 키보드와 포인터를 지원한다.
- 서버/필터 테스트 92개, 타입 검사, 프로덕션 빌드 통과. 수정 파일 ESLint 오류 없음.
- 로컬 Edge에서 실제 학교 계정으로 학년+연도 필터, 포인터 드래그, 키보드 변경, 0건에서 전체 보기, SCAMPER 초기화, 모바일 가로 넘침 없음, pageerror 0을 확인했다.
